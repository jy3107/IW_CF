# Counterfactuals Independent Research Work
• Built an automated backend pipeline to evaluate image captioning models using counterfactual datasets with
removed visual attributes

• Integrated Florence-2 and Segment Anything Model (SAM) for object detection; implemented scripted
workflows with Attentive-Eraser to generate attribute-controlled counterfactuals 

• Measured semantic drift using BLIP and ViT caption models; found 40%+ change in keywords in disability removals
